# API 계약 초안

현재 백엔드 엔드포인트는 미확정이다. 프론트는 `EXPO_PUBLIC_API_BASE_URL` 아래로만 요청한다.

## 제안 엔드포인트

- `POST /v1/analyses`: 사진과 분위기 키워드 3개로 분석 생성
- `GET /v1/analyses/:id`: 분석 상태 및 결과 조회
- `DELETE /v1/analyses/:id/photo`: 원본 사진 삭제 요청

## 확인 필요

- 이미지 전송 형식(multipart 또는 사전 서명 업로드)
- 비동기 처리 상태와 polling 간격
- 얼굴 미검출, 복수 얼굴, 네트워크/생성 실패 오류 코드
- 원본/생성 이미지 보관 기간과 즉시 삭제 동작
- 인증 포함 여부

실제 AI 공급자 키는 앱에 전달하지 않으며 백엔드에서만 관리한다.
