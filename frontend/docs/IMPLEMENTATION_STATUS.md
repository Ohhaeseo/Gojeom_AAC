# GO. 프론트엔드 구현 상태

## 구현 완료

- iPhone 세로 화면 기준 Expo React Native + TypeScript + Expo Router 구조
- 공식 워드마크와 얼굴 로고를 사용한 실행 화면 전환
- 로그인/회원가입 UI와 소셜 로그인 로고 배치(백엔드 미연동)
- 사진 등록, 우선순위, 신체 정보, 선택 정보, 프로필 분석 플로우
- 피부 상태 대시보드를 포함한 홈 화면
- 분석 입력, 키워드 선택, 분석 중/완료, 결과, 서랍 저장 플로우
- 목표 설계 중/완료를 목표 설계 화면 위 블러 오버레이로 처리
- 루틴 완료 스위치, 프로필, 설정, 화면 이탈/정보 삭제 팝업
- 공통 색상/타이포그래피/버튼/헤더/하단 네비게이션/모달 컴포넌트
- API.md의 주요 enum, 요청 제약, 성공/실패 envelope를 타입과 서비스 계층에 반영

## 현재 동작 방식

- API가 연결되기 전이므로 앱 데이터와 분석 상태 전환은 프론트엔드 mock으로 동작한다.
- 소셜 로그인은 로고와 화면 이동만 구현되어 있다.
- 분석 결과 이미지와 피부 대시보드 수치는 발표용 mock이며 외모 점수가 아니다.
- 사진·인증·AI 처리·영구 저장은 실제 백엔드 연결 시 교체해야 한다.

## 실행

```bash
npm install
npm run start
```

iPhone 실기기에서는 Expo Go로 QR을 열고 주요 플로우를 확인한다. 네이티브 기능이나 배포 설정이 추가되면 Development Build로 전환한다.

## 검증

- `npm run typecheck`
- `npm run lint`
- `npx expo export --platform web --output-dir dist-check`
