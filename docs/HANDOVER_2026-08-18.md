## 3. 오답 노트 추가분 — AGENTS.md §4-1로 옮길 것

### N-13. 라이브러리가 웹에서 조용히 죽는다

`react-native-draggable-flatlist`를 넣었더니 **끌어도 아무 일이 없었다.** 셀 위치를
`findNodeHandle`로 재는데 **RN Web에 그 API가 없다.** 콘솔에 경고 한 줄만 남기고
에러도 던지지 않아, 화면만 보면 "왜 안 되지"에서 멈춘다.

**재발 방지** — 네이티브 라이브러리를 웹에 쓸 때는 **실제로 그 동작을 해 보고**
확인한다. 렌더링이 된다고 동작하는 것이 아니다. 지금은 `PanResponder`(코어)로
직접 만들었다(`DragList`). **끌기와 ▲▼ 버튼을 둘 다 준다** — 순서를 바꾸는 길이
최소 하나는 늘 열려 있어야 한다.

### N-14. 애너테이션과 선언 사이에 끼워 넣지 않는다

`RoutineRenameRequest`를 `RoutineSummary` 바로 위에 넣으면서
`@JsonInclude(ALWAYS)`를 떼어놨다. 애너테이션이 새 레코드에 붙어 **경로 A 응답에서
`category: null` 키가 사라졌다.** 기존 회귀 테스트가 잡아줬다.

### N-15. 마이그레이션을 쓰기 전에 기존 것을 전부 읽는다

V9에 `CREATE UNIQUE INDEX ux_consents_user_code`를 넣었는데 **V1이 이미 만들고
있었다.** V1의 앞부분만 보고 뒤쪽 인덱스 선언을 놓쳤다. `grep`으로 먼저 확인한다.

### N-16. 한글은 psql뿐 아니라 **curl에서도** 깨진다

N-5는 psql만 말하지만 **curl 본문의 한글 닉네임도 셸을 거치며 깨져** 400이 났다.
점검용 데이터는 ASCII로 쓰고, 한글이 꼭 필요하면 **UTF-8 파일로 만들어**
`psql -f`처럼 파일로 넘긴다.

## 4. 이번에 만든 것 — 요점만

### 만 14세 미만 차단 (`2aa376d`)

- **생년월일을 `users`에 뒀다.** `profiles.birth_date`는 프로필이 사진·우선순위까지
  받은 뒤에야 생겨서 늦다. 나이 확인은 **어떤 개인정보든 수집하기 전에** 끝나야
  한다. 같은 사실을 두 곳에 두지 않으려고 프로필 쪽은 없앴다(V9).
- 동의 4항목으로 분리. 얼굴 사진·건강 정보는 **민감정보**라 `BIOMETRIC`으로 따로.
- **거부한 항목도 행을 남긴다.** "물어봤는데 거부"와 "아직 안 물어봄"은 다르다.
- **Google 최초 로그인도 회원가입이다.** 값이 없으면 `CONSENT_REQUIRED`로 돌려보낸다.

| 실측 | 결과 |
| --- | --- |
| 만 13세 | 403 `PROFILE_UNDERAGE` |
| **만 14세 생일 당일** | **201 통과** ← 법이 막는 것은 *미만*이다 |
| 민감정보 동의 누락 | 403 `CONSENT_REQUIRED` |

### 태스크 시점 분리 (`fcb3716`)

완료 체크가 태스크 단위라 "아침, 저녁"이 한 줄이면 아침만 한 상태를 표현할 수
없었다. **프롬프트와 코드 두 곳**에서 막는다(`TaskTimingSplitter`).

**잘못 자르는 쪽이 못 자르는 쪽보다 나쁘다.** "과일 먹기"를 "일 먹기"로 만드느니
한 줄로 두는 편이 낫다 — 단어 구분자(과·와·및)는 **앞뒤가 띄어져 있을 때만** 자르고,
5조각을 넘으면 나누지 않는다.

> 실측: 6개월 피부 목표에서 세안·보습이 아침/저녁으로 갈려 **taskCount 120**.

### 루틴 품질 · 인바디 · 식단 (`42a5690`)

프롬프트에 구성 규칙, 신체 정보 사용법, 식사 방향을 더했다.

**숫자를 사용자에게 그대로 읽어 주지 않는다** — "체지방 25kg이므로"처럼 쓰면
진단처럼 들린다(규칙 4). 그 사실이 반영된 태스크만 낸다.

실측 결과(체지방 26.5 · 골격근 30.1 · 수면 5.5h · "근력을 키우고 싶다"):

```
기상 직후 물 마시기 | 기상 직후   | 300ml
아침 단백질 챙기기  | 아침
점심 후 걷기       | 점심 후     | 10분
저녁 근력운동 하기  | 주 4회 저녁 | 20회
자기 전 스트레칭    | 자기 전
```

식사 방향: "끼니마다 단백질을 충분히 챙기고, 늦은 시간의 과식을 줄여보세요…"

## 7. 알아두면 시간 아끼는 것

- **한글을 셸로 파이프하지 않는다** (N-5 · N-16). psql도 curl도 마찬가지다.
  꼭 필요하면 UTF-8 파일로 만들어 `psql -f`로 넘긴다.
- **`.env`를 고쳐도 떠 있는 프로세스는 옛 값을 들고 있다.** 백엔드·Expo 둘 다 재시작.
- **마이그레이션을 추가했으면 백엔드를 재시작해야 적용된다.** 이번에 V10을 만들고
  재시작을 잊어 "칼럼이 없다"로 한 번 막혔다.
- **Google 설정 확인** — 쓰레기 토큰으로 응답 코드를 가른다. **401**이면 정상,
  **500**이면 `GOOGLE_CLIENT_ID` 미주입.
  ```bash
  curl -s -w "\nHTTP %{http_code}\n" -X POST http://localhost:8080/api/v1/auth/oauth/google \
    -H "Content-Type: application/json" -d '{"idToken":"not-a-real-token"}'
  ```
- **커밋을 나눌 때** — `git stash push --keep-index`로 각 커밋 상태를 격리해
  typecheck·lint를 돌리면 중간 커밋이 깨지지 않는다. 파일이 커밋 경계를 걸치면
  `git apply`로 훅만 골라 적용한다.
- **테스트 계정을 만들었으면 DB와 브라우저 localStorage 양쪽을** 정리한다.
