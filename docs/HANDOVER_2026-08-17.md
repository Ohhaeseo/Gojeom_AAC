## 5. 오답 노트 추가분

AGENTS.md §4-1에 정식 항목으로 옮길 것. 여기에는 요약만 남긴다.

### N-10. 웹 picker의 `blob:` URI에는 확장자가 없다

업로드 Content-Type을 **URI 확장자**로 정하고 있었다. 웹에서 picker가 주는 `blob:http://localhost:8081/<uuid>`에는 확장자가 없어 **무엇을 고르든 `image/jpeg`로 신고**됐다. PNG를 고르면 S3 업로드까지 성공한 뒤 프로필 등록에서 400이 나고 스토리지에는 고아 객체만 남았다.

**재발 방지** — `Blob.type`을 정본으로 쓴다. 네이티브는 `file:///...jpg`라 확장자가 있어 이 문제가 드러나지 않았다. 서버가 실제 바이트와 신고한 형식을 대조하면서(`ImageContentInspector`) 비로소 표면화됐다.

> **플랫폼마다 URI 모양이 다르다.** 파일 메타데이터는 경로 문자열이 아니라 객체 자신에게 묻는다.

### N-11. 중첩 `Pressable`은 부모까지 함께 발동한다

`−`·`+` 스테퍼를 카드 `Pressable` 안에 뒀더니, 누를 때 이벤트가 카드로 올라가 **카드가 접혔다.** 특히 **비활성 `Pressable`은 이벤트를 삼키지도 않아서** 최소값에서 `−`를 누르면 카드가 통째로 닫혔다.

**재발 방지** — 누를 수 있는 영역은 헤더만 두고, 내부 컨트롤은 형제로 뺐다. 서랍의 삭제 버튼도 같은 이유로 카드 밖에 있다.

> **카드 안에 버튼을 넣을 때는 카드 전체를 누르게 만들지 않는다.**

### N-12. 화면이 서버 데이터를 메모리로만 들고 있다

`result`·`saved`·`tasks`가 `AppState` 메모리에만 있어 **새로고침하면 사라진다.** 그래서 서랍에 결과가 저장돼 있는데도 루틴 화면이 "아직 저장한 분석이 없어요"라고 말했다.

**재발 방지** — "있는지 없는지"를 판단할 때는 메모리가 아니라 **서버에 물어본다.** 루틴 화면은 `loadDrawer()`로 개수를 받아 쓴다.

> 홈 화면의 `최근 분석 결과`와 `/goal`의 빈 화면도 같은 이유로 새로고침 후 비어 보였다.
> **둘 다 고쳤다 (§10).** 남은 곳이 또 있는지는 "메모리만 보고 있는지"를 기준으로 찾으면 된다.

### 구조 — 클라이언트 ID 하나만 백엔드에 간다

`GoogleTokenVerifier`가 **audience를 정확히 하나만** 허용한다. 그래서 어느 플랫폼에서 오든
ID 토큰의 `aud`가 **웹 클라이언트 ID 하나**로 통일돼야 한다.

| 콘솔 클라이언트 | 콘솔 등록 | 백엔드 | 프론트 |
| --- | --- | --- | --- |
| **웹 애플리케이션** | ✅ | ✅ `GOOGLE_CLIENT_ID` | ✅ `EXPO_PUBLIC_GOOGLE_WEB_CLIENT_ID` |
| Android (`com.gojeom.producer`) | ✅ | ❌ | ❌ |
| iOS (`com.gojeom.producer`) | ✅ | ❌ | URL 스킴만 |

Android·iOS 클라이언트는 **만들기만 하고 어디에도 넣지 않는다.** 구글이 패키지명·서명·번들 ID를
검증하는 데만 쓴다. 네이티브 SDK에 웹 ID를 `serverClientId`로 넘기면 `aud`는 웹 ID로 유지되고
`azp`에만 플랫폼 ID가 들어간다.

> **범위는 `openid`·`email`·`profile` 셋뿐이다.** 전부 민감하지 않은 범위라 **구글 보안 심사가
> 필요 없다.** 민감 범위를 하나라도 추가하면 프로덕션 게시에 심사가 붙는다 — 추가하지 않는다.

### 설정이 먹었는지 확인하는 법

쓰레기 토큰을 던져 응답 코드로 가른다.

```bash
curl -s -w "\nHTTP %{http_code}\n" -X POST http://localhost:8080/api/v1/auth/oauth/google \
  -H "Content-Type: application/json" -d '{"idToken":"not-a-real-token"}'
```

| 응답 | 뜻 |
| --- | --- |
| **401** `AUTH_INVALID_CREDENTIALS` | **정상.** 설정은 됐고 토큰만 가짜다 |
| **500** `INTERNAL_ERROR` | `verifier == null` — `GOOGLE_CLIENT_ID`가 주입되지 않았다 |

> `.env`를 고쳐도 **이미 떠 있는 프로세스는 옛 값을 들고 있다.** 백엔드·Expo 둘 다 재시작해야 한다.

### 웹 구현 — 시안 아이콘 아래 Google의 진짜 버튼

`GoogleSignInButton.web.tsx`가 시안 아이콘을 그리고 **그 위에 Google이 렌더한 버튼을 투명하게
얹는다.** 우리가 클릭을 흉내 내지 않고 사용자가 Google 버튼 자신을 누르게 하려는 것이다.

- Google 버튼은 `type: 'icon'`이라 **40×40**, 슬롯은 52×52 — 옆 버튼(네이버·전화)의 눌림 영역을
  침범하지 않는다. **크기를 키우면 이웃을 덮는다.** (N-11과 같은 함정)
- `ux_mode: 'popup'`이라 **리디렉션 URI가 필요 없다.** 콘솔에는 **승인된 JavaScript 원본**만 넣는다
  (`http://localhost:8081`, 배포 후 실제 오리진 추가).
- GIS 콜백의 `credential`이 곧 ID 토큰이다. 프론트는 **열어보지 않고** 그대로 서버에 넘긴다.

### 네이티브가 아직 안 되는 이유

`@react-native-google-signin/google-signin`은 네이티브 모듈이라 **Expo Go에서 못 돈다.**
`npx expo prebuild` 또는 EAS 개발 빌드가 먼저 있어야 한다 — 미뤄둔 **실기기 테스트(§6 3번)와
같이 와야 하는 작업**이다. 그때 `GoogleSignInButton.tsx`(현재 안내 문구만 띄우는 자리)를 채우면 된다.

> `expo-auth-session`은 Expo Go에서 돌지만 **플랫폼별 클라이언트 ID를 써서 `aud`가 갈라진다.**
> 지금 검증기에 그대로 걸리므로 쓰지 않는다.

### 검증한 것 (브라우저 실측)

따르는 작업이라 사용자가 직접 눌러 확인해야 한다.

## 10. 작은 항목 3건 (2026-08-17 추가)

### 7. 최대 폭 — 껍데기 전체를 묶는다

`tokens.layout.maxWidth = 458`(시안 기준 폭). `AppScreen`이 **헤더·내용·하단 네비를 한 `View`로
감싸** 셋에 같은 폭을 건다.

- **내용만 묶으면 안 된다.** 헤더와 네비가 따로 전체 폭으로 늘어나 어긋난다.
- `width: '100%'` + `maxWidth`라 **좁은 화면(실기기)에서는 시안 폭 그대로** 돌고, 넓은 화면에서만
  걸린다.
- **오버레이(`overlay` prop)는 껍데기 밖에 뒀다.** 모달·로딩은 화면 전체를 덮어야 한다.

실측(1280px 뷰포트): shell `x=411 w=458` 중앙 정렬 · 가장 큰 카드 **738 → 458** · 가로 스크롤 없음.

### 8. `/goal` 막다른 길 — 두 갈래 + 조건부 세 번째

분석 결과 없이 들어가면 `고점 분석하기` 버튼 하나뿐이었다. 이제:

| 카드 | 이동 |
| --- | --- |
| **고점 분석하기** (강조) | `/analysis-new` |
| **진단 없이 목표 만들기** | `/routine-new` (경로 B) |
| 서랍에서 분석 가져오기 | `/drawer` — **서랍에 저장분이 있을 때만 나온다** |

세 번째 카드는 N-12 때문에 붙였다. `result`가 메모리에만 있어 **새로고침하면 사라지므로**,
"분석 결과가 없다"가 사실이 아닐 수 있다. `loadDrawer()`로 서버에 물어보고 실제로 있으면
가져올 길을 준다.

### 9. 홈의 `최근 분석 결과` — 서버에 물어본다

같은 N-12. `result`가 비어도 서랍에 저장분이 있으면 **그것으로 카드를 그린다.**

- `useFocusEffect` + `loadDrawer()` → `recent[0] ?? all[0]`
- 메모리의 `result`가 우선, 없으면 서버가 준 최근 저장분
- 카드를 누르면 `openSavedResult()` 후 `/analysis-result`로 간다 (서랍 화면과 같은 동작)

> **`DrawerItem`에 필요한 것이 다 있다** — `thumbnailUrl` · `title` · `analyzedAt`. 별도 API가 필요 없다.
