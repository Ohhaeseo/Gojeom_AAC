## 💡 어떤 서비스인가요?

**GO. (고점)**은 사용자의 현재 사진과 원하는 분위기의 사진·텍스트를 AI로 분석해,  
나에게 자연스럽게 어울리는 **스타일 변화 우선순위와 예상 이미지**를 제공하는 퍼스널 이미지 컨설팅 서비스입니다.

단순히 다른 사람의 모습을 따라 하는 대신, 원하는 분위기를 헤어·눈썹·메이크업·컬러 등의 요소로 나누고 **지금의 나에게 적용할 방법**을 알려줍니다.

## 🚀 핵심 경험

```text
📷 현재 사진 등록
        ↓
🖼️ 추구미 사진·텍스트 입력
        ↓
🏷️ AI 분위기 키워드 분석 및 선택
        ↓
📋 유지할 요소 + 변화 우선순위 Top 3
        ↓
✨ 선택한 변화가 반영된 예상 이미지 생성
```

## 🌟 주요 기능

- 사진 또는 텍스트로 원하는 분위기 입력
- AI 기반 추구미 키워드와 스타일 요소 분석
- 현재 이미지에서 유지할 요소와 조절할 요소 제안
- 부담이 적고 효과적인 변화 **Top 3** 추천
- 사용자가 선택한 변화가 반영된 참고용 이미지 생성
- 로그인 없이 결과 확인 및 이미지 다운로드

## 🧭 서비스 원칙

> 외모를 점수화하거나 타인의 얼굴을 복제하지 않습니다.

- **평가보다 해석** — 결점이 아닌 분위기 구성 요소를 설명합니다.
- **복제보다 적용** — 참고 이미지의 스타일만 나에게 맞게 적용합니다.
- **이미지보다 행동** — 실제로 시도할 수 있는 변화 순서를 제안합니다.
- **사용자 선택 우선** — AI 추천보다 사용자의 선택을 우선합니다.
